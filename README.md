Java Swing Login:
Aplicación de escritorio desarrollada en Java Swing que implementa un formulario básico de inicio de sesión. El proyecto fue realizado como una práctica para aprender a crear interfaces gráficas y manejar eventos utilizando componentes de Java Swing.

Descripción:
El proyecto consiste en una ventana de inicio de sesión donde el usuario debe ingresar un nombre de usuario y una contraseña.

Al presionar el botón Enviar, el sistema valida los datos introducidos y muestra un mensaje dependiendo del resultado:
  -Inicio de sesión correcto.
  -Contraseña incorrecta.
  -Usuario incorrecto.
